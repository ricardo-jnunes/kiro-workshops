## Kiro Structure - Spec-Driven Development

```
your-project/
├── .kiro/                       # Main Kiro configuration folder
│   ├── product.md               # Scope and purpose of the project
│   ├── tech.md                  # Tech stack, versions, and dependencies
│   ├── structure.md             # Maps out key folders and code organization
│   └── steering/                # Markdown files detailing rules and conventions
│       ├── coding-style.md      # Formatting and architectural decisions
│       └── testing-guidelines.md# Expected coverage and framework rules
├── src/                         # Your actual application code
└── tests/                       # Project test suites
```
